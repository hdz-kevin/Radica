# Docs

## MVP is built in teaching slices
The canonical MVP spec is docs/mvp_plan.md. Do not implement the full product in one pass. Build one numbered slice at a time (data foundation, catalog, publish, photos, filters, OAuth, admin). After each slice, explain the architecture and Laravel/backend concepts so Kevin can learn. Do not skip ahead to Socialite before the listing domain exists. Mapbox and a pin map are out of the MVP; the catalog is cards.
