# Docs

## MVP is built in teaching slices
The canonical MVP spec is docs/mvp_plan.md. Do not implement the full product in one pass. Build one numbered slice at a time (data foundation, catalog, publish, photos, filters, map, OAuth, admin). After each slice, explain the architecture and Laravel/backend concepts so Kevin can learn. Do not skip ahead to Mapbox or Socialite before the listing domain exists.
